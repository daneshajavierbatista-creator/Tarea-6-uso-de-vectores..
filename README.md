Repositorio dedicado a la práctica y resolución de ejercicios fundamentales sobre el uso de vectores (arreglos unidimensionales) en la lógica de programación. Este proyecto forma parte de las actividades orientadas al fortalecimiento del pensamiento computacional y la estructuración de datos básicos.

Este código en C++ gestiona el inventario de una tienda mediante una estructura de productos, inicializando una lista con cinco artículos a la que luego añade un sexto ("Azúcar"), muestra todos sus elementos en pantalla, actualiza el precio del "Arroz" a 90, calcula e imprime el precio promedio de todo el inventario, muestra el nombre del primer artículo y finalmente identifica y despliega el producto más costoso ("Café").
